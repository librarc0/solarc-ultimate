# 功能规范: EaglesPower — 飞盘队伍 OpenSkill 评分系统（整体规范）

**功能分支**: `master`
**创建时间**: 2026-03-11
**状态**: 草稿
**输入**: 用户描述: "FastAPI 后端，Vue 3 前端，数据库根据最适配的来选择，在NAS上用Docker部署，要求产品可以在网页端和移动端使用"

## 项目概述

EaglesPower 是一套为飞盘（Ultimate Frisbee / Goal Frisbee）队伍设计的私有化 OpenSkill 评分管理系统。
替代原有基于 Python 脚本 + Excel 的离线工具（Solar System MIX 2.0），提供：
- **Web + 移动端双端访问**：响应式 PWA，手机浏览器即可使用，无需安装 App
- **NAS Docker 一键部署**：支持群晖/QNAP/绿联/极空间等主流 NAS
- **实时评分更新**：每场比赛提交后立即触发 OpenSkill 重算
- **私有化数据**：所有数据存储在本地 NAS，不依赖公网

## 技术选型决策

| 组件 | 选型 | 选型理由 |
|------|------|---------|
| **后端框架** | Python 3.11 + FastAPI | 与原 Solar System 同语言，生态成熟，异步性能好 |
| **前端框架** | Vue 3 + TypeScript | 渐进式框架，配合 Vant 4 移动端体验优秀 |
| **移动端 UI** | Vant 4 | 专为移动端设计，组件丰富（表单、底部抽屉、tab 栏） |
| **数据库** | SQLite（主选） + PostgreSQL（可选扩展） | SQLite 单文件适配 NAS 无服务器环境；后期可无缝迁移 PostgreSQL |
| **ORM** | SQLAlchemy 2.0 (async) | FastAPI 生态最佳搭配，支持异步查询 |
| **容器化** | Docker + Docker Compose | NAS 标准容器运行时，一键部署 |
| **评分算法** | OpenSkill (openskill 6.2.0)，PlackettLuce 模型 | Weng-Lin 算法，比 TrueSkill 更宽松的开源协议 |
| **认证** | JWT (python-jose) + bcrypt | 无状态认证适配 NAS 单节点部署 |

## 用户场景与测试 *(必填)*

### 用户故事 1 - 全新 NAS 部署后首次使用 (优先级: P1)

队伍管理员在 NAS 上运行 `docker compose up -d`，通过局域网 IP 访问系统，完成队伍创建、管理员注册，并引导队员加入。

**验收场景**:

1. **给定** NAS 上安装了 Docker，**当** 克隆仓库并运行 `docker compose up -d`，**那么** 服务在 2 分钟内就绪，`GET /health` 返回 HTTP 200。
2. **给定** 服务就绪，**当** 使用局域网 IP（如 `192.168.1.100:8080`）在手机浏览器打开，**那么** 页面正常加载，首次访问自动跳转注册页。
3. **给定** 第一个用户注册，**当** 填写账号/密码并提交，**那么** 该用户自动成为 `owner`，系统跳转到管理员首页。

### 用户故事 2 - 管理员手机端录入比赛 (优先级: P1)

赛场边，管理员用手机完成一场内战全程录入（阵容分配 → 计时 → 进球/助攻 → 提交评分），全程操作流畅，3 步内完成录入提交。

**验收场景**:

1. **给定** 管理员已登录，**当** 点击底部导航"+"按钮，**那么** 进入比赛类型选择页（内战/外战/快速录入）。
2. **给定** 选择内战，**当** 完成阵容分配并提交，**那么** 评分在 500ms 内完成更新，排行榜数据实时刷新。

### 用户故事 3 - 队员查看个人战力面板 (优先级: P1)

队员登录后在玩家卡片页查看自己的五维雷达图、μ/σ 曲线和最近比赛记录，感知能力成长轨迹。

**验收场景**:

1. **给定** 队员已登录，**当** 进入个人主页 tab，**那么** 展示玩家卡片（雷达图 + μ/σ + 近 10 场折线图 + 近 20 场比赛记录）。

## 非功能需求

| 需求 | 指标 |
|------|------|
| API 响应时间 | p95 < 500ms（本地 NAS 局域网） |
| 移动端最小宽度 | 375px（iPhone SE），主流程 3 步内完成 |
| Docker 启动时间 | < 2 分钟（含数据库迁移） |
| 数据完整性 | 支持 Level 0–3 降级，不因数据缺失拒绝录入 |
| 安全基线 | OWASP Top 10 合规，bcrypt 密码哈希，JWT 鉴权 |
| 存储 | SQLite 单文件，NAS 挂载卷持久化 |
